📋 标准文件命名规则
文件类型文件名格式示例
形变速率vel_{path}_{frame}_{YYYYMM}_{YYYYMM}.tifvel_157_127_201809_201812.tif
速率（ERA5大气校正）vel_E_{path}_{frame}_{YYYYMM}_{YYYYMM}.tifvel_E_157_127_201809_201812.tif
累计形变cum_rd_{path}_{frame}_{YYYYMM}_{YYYYMM}.h5cum_rd_157_127_201809_201812.h5
累计形变（ERA5）cum_rdE_{path}_{frame}_{YYYYMM}_{YYYYMM}.h5cum_rdE_157_127_201809_201812.h5
水体掩膜water_{path}_{frame}_{YYYYMM}_{YYYYMM}.tifwater_157_127_201809_201812.tif
时间相干性tc_{path}_{frame}_{YYYYMM}_{YYYYMM}.tiftc_157_127_201809_201812.tif
命名说明：
· path / frame — Sentinel-1 轨道号（如 157、127）
· YYYYMM — 年月，精确到月（如 201809 = 2018年9月）
· E — 使用了 ERA5 大气校正的标记
· rd — ramp + demErr 纠偏的标记
· 系统扫描时 vel_*.tif 必须存在，其余文件可选
