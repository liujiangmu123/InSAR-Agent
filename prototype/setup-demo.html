步骤 2 · 引擎环境

InSAR 引擎（ISCE2 / MintPy / SNAPHU）运行在独立 conda 环境中。在终端逐条执行以下命令，完成后回到第 1 步重新检测。

检测到 Conda：D:\miniconda3，以下命令可直接执行。
1. 创建引擎环境 
conda create -n insar-engine python=3.10 -y
2. 安装 InSAR 引擎
约需 10–20 分钟，视网络情况
conda install -n insar-engine -c conda-forge isce2 mintpy snaphu -y

全部执行完成后，回到第 1 步点「重新检测」；若安装到了自定义位置，再在第 3 步填写路径。
