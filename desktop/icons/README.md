# desktop/icons —— 程序图标

InSAR Agent 桌面端(Tauri)的正式程序图标。全部资产由 `make_icons.py` 用
Pillow **程序化绘制**(纯离屏,无弹窗,不依赖任何外部素材),幂等可重跑。

## 设计说明

主题:**「卫星 + 干涉条纹」** —— 一颗 SAR 卫星对地观测,地表是一幅缠绕的
干涉相位图。

- **底**:深空蓝竖向渐变(`#10264F → #071024`)圆角方形(圆角 22.5%),
  缀少量星点(固定随机种子,输出像素级稳定);
- **干涉条纹**:中央偏右下的同心弧形条纹,色相沿半径循环
  (红→黄→绿→青→蓝→紫,模拟 InSAR 干涉图中缠绕的相位),圆心处为
  暖白亮核 + 蓝色辉光(形变中心的意象);条纹带柔光层,近似干涉图的
  连续渐变;
- **卫星**:左上角近白剪影 —— 本体 + 双太阳翼(带栅线)+ 碟形天线,
  翼展与波束方向垂直;一束半透明雷达波束从天线指向条纹圆心;
- **可见性**:彩虹条纹、近白卫星、浅色内描边(`#DEECFF`,约 1.1% 线宽)
  均为亮色元素,保证深色任务栏/深色 Dock 上轮廓清晰;≤32px 的输出做了
  饱和度/对比度补偿,避免小图标发灰。

绘制细节:在 2048×2048 母版上绘制(512 逻辑尺寸 × 4x 超采样),再用
LANCZOS 缩小得到各尺寸,天然抗锯齿。

## 文件清单

| 文件 | 说明 |
| --- | --- |
| `icon.png` | 512×512 主图(RGBA) |
| `icon-16/32/48/128/256.png` | 各尺寸 RGBA PNG |
| `32x32.png`、`128x128.png` | `tauri.conf.json` `bundle.icon` 引用的旧命名,与 `icon-32/128.png` 字节一致 |
| `icon.ico` | 16/32/48/128/256 多尺寸打包(BMP-in-ICO,对 rc.exe 与 tauri 代码生成用的 `ico` crate 兼容性最好) |
| `preview.png` | 自检拼板:256 版放大 2x + 深/浅底 128/48/32/16 对照 |
| `make_icons.py` | 生成脚本(唯一"源文件",其余均为产物) |

## 重新生成

在**项目根目录**执行:

```powershell
# 若 .venv 不存在先创建并装 Pillow
py -m venv .venv
.venv\Scripts\python.exe -m pip install pillow

.venv\Scripts\python.exe desktop\icons\make_icons.py
```

脚本幂等:重复运行覆盖本目录全部产物;随机星点用固定种子,同版本
Pillow 下输出字节级稳定。调整设计只需改 `make_icons.py` 顶部的配色与
构图常量(`BG_*`、`FRINGE_C`、`N_RINGS` 等)。
